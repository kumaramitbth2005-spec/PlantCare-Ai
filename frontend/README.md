# PlantCare AI - Frontend Dashboard

This is the user interface for the PlantCare AI platform, built with **Next.js 14**, **React**, and **Tailwind CSS**.

## 🚀 Features
- **Dynamic Dashboard**: Real-time analytics and scan history.
- **AI Scanner Interface**: Easy-to-use upload and results display.
- **Responsive Design**: Works seamlessly on Mobile, Tablet, and Desktop.
- **Glassmorphism UI**: Modern, premium aesthetic with smooth animations.

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Data Visualization**: Chart.js
- **Icons**: Lucide React

## 🛠️ Setup & Installation
1.  **Install Dependencies**:
    ```bash
    npm install
    ```
2.  **Run Development Server**:
    ```bash
    npm run dev
    ```
    Open [http://localhost:3000](http://localhost:3000) to view the app.

## 🏗️ Structure
- `/src/components`: Reusable UI elements (Navbar, Sidebar, Modals).
- `/src/app`: Page routes and layouts.
- `/public`: Static assets and images.

## 📄 Environment Setup
Ensure `.env.local` is configured:
```env
NEXT_PUBLIC_API_URL=http://localhost:8000
```
